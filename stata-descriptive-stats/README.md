# 作业二 · 描述性统计分析（Stata）

对 Stata 自带数据集 **nlsw88**（1988 年美国国家青年女性纵向调查）中的两个连续变量做描述性统计。

- **分析变量**：`wage`（小时工资，美元）与 `hours`（每周通常工作小时数）
- **运行环境**：Stata 12 SE（Windows）
- **分析日期**：2026-10-30

---

## 一、结果摘要

| 统计量 | wage（小时工资） | hours（每周工时） |
| ---: | ---: | ---: |
| 观测值 | 2,246 | 2,242 |
| 均值 | 7.7669 | 37.2181 |
| 标准差 | 5.7555 | 10.5091 |
| 最小值 | 1.0050 | 1.0000 |
| 25 分位数 | 4.2593 | 35.0000 |
| **中位数** | **6.2723** | **40.0000** |
| 75 分位数 | 9.5974 | 40.0000 |
| 最大值 | 40.7466 | 80.0000 |
| 偏度 | 3.0962 | −0.7337 |
| 峰度 | 15.8545 | 4.9252 |

> 注：各变量分别剔除自身缺失值后计算，因此两列观测值数不同（`hours` 有 4 个缺失）。
> 偏度为 0 表示分布对称，峰度为 3 表示正态分布的陡峭程度。

### 两条需要写进报告的结论

**1. 工资分布严重右偏，应报告中位数而非均值。**
`wage` 的偏度为 3.10、峰度为 15.85，属于典型的右偏厚尾分布。均值 7.77 美元被少数高收入者拉高（最高 40.75 美元，是最低值的约 40 倍），而中位数只有 6.27 美元。**若只报告均值，会把典型劳动者的工资高估约 24%。**

**2. `hours` 呈左偏，且高度集中在 40 小时。**
偏度 −0.73，25 分位数、中位数、75 分位数均为 35 / 40 / 40，说明约半数样本的工时集中在每周 40 小时附近（标准工时制）；最小值为 1 小时、最大值为 80 小时，属于少量兼职与超时工作的极端值。

## 二、如何复现这份结果

**环境要求**：Stata 12 及以上（代码未使用任何 Stata 13 以后才引入的命令，如 `putexcel`、`putdocx`、`export delimited`、`misstable`）。

在 Stata 的 Command 窗口中依次执行：

```stata
cd "D:\Projects\personal-finance-dashboard\stata-descriptive-stats\code"
do descriptive_stats_v12.do
```

运行后将得到三样东西：

| 产出 | 说明 |
| --- | --- |
| Results 窗口中的表格 | 屏幕上的完整输出 |
| `descriptive_stats.csv` | 可用 Excel / WPS 直接打开，粘贴进 Word |
| `descriptive_stats.log` | 完整运行记录，含每一步命令与输出 |

**更换分析变量**：打开 do 文件，修改这一行即可。

```stata
global myvars  "wage hours"
```

**增加分组对比**：把下面这行的引号内填上分组变量（如 `union` 工会 / `collgrad` 是否大学毕业），会额外输出一张分组对比表。

```stata
global mygroup ""
```

> ⚠️ 导出 CSV 前请先关闭已打开的 `descriptive_stats.csv`。若文件被 Excel 占用导致写入失败，脚本会自动改存为 `descriptive_stats_new.csv` 并在屏幕上提示。

## 三、文件清单

| 文件 | 作用 |
| --- | --- |
| `code/descriptive_stats_v12.do` | 分析脚本本体（**GBK 编码**，Stata 12 直接可读） |
| `results/descriptive_stats.csv` | 描述性统计表（中文表头，Excel 可直接打开） |

> **关于编码**：`.do` 文件保存为 GBK，因为 Stata 12（2011 年）不支持 UTF-8，用 UTF-8 打开会显示乱码。
> 因此在 GitHub 网页预览 `.do` 文件时，中文注释可能显示为乱码——**这是正常的**，下载后用 Stata 打开即为正常中文，不影响运行。

**原始数据集未包含在本作业目录中**：`nlsw88.dta` 是 Stata 自带的示例数据，任何装有 Stata 的电脑执行 `sysuse nlsw88, clear` 均可获得，无需重复上传，也不便于传播。
