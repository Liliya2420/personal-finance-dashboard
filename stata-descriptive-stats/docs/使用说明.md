# Stata 描述性统计表 —— 使用说明

> 适用软件：**Stata 12**（本机装的是 Stata 12 SE，装在 `E:\学委工作\stata安装包\Stata12.0（已破解版）\`）
> 文件位置：`E:\stata_work\descriptive_stats_v12.do`

---

## 一、三步跑出结果

1. 打开 Stata 12
2. 菜单 **File → Open**，右下角文件类型选 **Do-files (\*.do)**，打开 `descriptive_stats_v12.do`
3. 按 **Ctrl + D**

跑完会得到：

| 产物 | 说明 |
|---|---|
| 屏幕上的表格 | 立刻能看到，写作业时对着抄就行 |
| `descriptive_stats.csv` | Excel / WPS 双击打开，可直接粘进 Word |
| `descriptive_stats.log` | 整个运行过程的文字记录，出问题给我看这个 |

文件都在 Stata 的**当前工作目录**里。想指定位置，把 do 文件开头那行注释（`cd "E:\stata_work"`）前面的 `*` 去掉。

## 二、我该怎么换成自己的变量？

打开 do 文件，找到这一段（带编号的那六行），只动它们：

```stata
global mydata  "nlsw88"        ← 1. 用哪个数据集
global howuse  "sysuse"        ← 2. 数据从哪来（自带就别动）
global myvars  "wage hours"    ← 4. ★最常改：分析哪两个变量
global mygroup ""              ← 5. 要不要分组
```

**改完记得 Ctrl + S 保存，再 Ctrl + D 运行。**

`nlsw88` 是美国 1988 年女性就业调查数据（2246 人），常用搭配：

| 变量 | 含义 | 建议搭配 |
|---|---|---|
| `wage` | 小时工资（美元） | wage + hours |
| `hours` | 每周通常工作时长 | wage + hours |
| `grade` | 受教育年限 | wage + grade |
| `tenure` | 在现单位工作年限 | wage + tenure |
| `age` | 年龄 | wage + age |

**第 5 行填 `union`（是否工会成员）或 `collgrad`（是否大学毕业），会额外出一张分组对比表** —— 论文里写"男/女、城市/农村、毕业/未毕业对比"时这一张特别有用。

## 三、十个统计量都是什么意思

不用背，先有个画面：把全班同学的身高排成一队。

| 表里的名字 | 英文 | 大白话 |
|---|---|---|
| 观测值 | N | 有几个人真的填了这一项 |
| 均值 | Mean | 平均数 |
| 标准差 | SD | 大家之间的差异有多大。SD 大 = 参差不齐；SD 小 = 都差不多 |
| 最小值 | Min | 最矮/最少的那个 |
| 25 分位数 | P25 | 排好队后，从矮数起第 25% 那个人的数 |
| 中位数 | Median | 正中间那个人的数（比均值抗干扰） |
| 75 分位数 | P75 | 第 75% 那个人的数 |
| 最大值 | Max | 最高/最多的那个 |
| 偏度 | Skewness | 分布歪不歪。**0 = 左右对称**；正数 = 右边拖了条长尾巴（比如工资，少数人极高） |
| 峰度 | Kurtosis | 尾巴厚不厚。**3 = 正态分布**（正常钟形）；大于 3 = 极端值比想象中多 |

**两个坑提醒你：**
- 每个变量是**各自**剔除缺失值后计算的，所以不同列的 N 可能不一样。这是标准做法，不用改。
- 中位数和均值差距很大时，说明数据偏了，这时候报告里应该突出**中位数**而不是均值。

## 四、可能会碰到的报错

| 报错的话 | 原因 | 怎么办 |
|---|---|---|
| 变量 xxx 在这个数据集里不存在 | 变量拼错，或者该数据里没这个变量 | 命令窗口敲 `describe`，看准变量名再改第 4 行 |
| 变量 xxx 是文字型的 | 选了性别、地区这类文字变量 | 换成数值变量；文字变量要用 `tab xxx` 看频率表 |
| csv 导出失败 | **那个 csv 正被 Excel 打开着** | 关掉 Excel 再跑一次 |
| 打开中文全是方框/乱码 | 文件编码不对 | 直接告诉我，我给你换成英文版 |

## 五、为什么这份代码要特意写成这样

Stata 12 是 2011 年的版本，比现在常见的 Stata 17/18 老很多。网上搜到的代码通常会用到这些命令，**它们在这台机器上都会报错**：

- `putexcel` —— 写 Excel，**Stata 13 才出现**
- `putdocx` —— 写 Word，**Stata 15 才出现**
- `export delimited` —— 导出 CSV，**Stata 13 才出现**
- `misstable` —— 缺失值表，**Stata 13 才出现**

所以这份脚本全部用最老的命令重写了：用 `file write` 手写 CSV（`file` 系列从很早就有），缺失值改用 `count if missing()` 循环统计，**不依赖任何需要联网安装的外部命令**。

顺着这条思路：以后拿到别人的 Stata 代码，如果报 `command xxx is unrecognized`，八成是因为你的 Stata 12 太老，不是你敲错了。
